# 🏢 دليل حزم وقواعد بيانات TriPro ERP للإطلاق والبيع التجاري
**TriPro Enterprise Resource Planning — Commercial Database Distribution Packages**

هذا المجلد يحتوي على **حزم التهيئة الشاملة والمجزأة** لقواعد بيانات عملاء TriPro ERP على منصة **Supabase (PostgreSQL 15+)**.
تم تصميم هذه الحزم لتكون **Idempotent (آمنة للتشغيل دون مسح أو تلف بيانات سابقة)** ومنظمة هندسياً لتمكينك من بيع النظام إما كمنظومة شاملة أو كباقات متخصصة لكل نشاط تجاري.

---

## 🚀 طريقة التثبيت والتسليم لعميل جديد (في 60 ثانية):

### السيناريو أ: العميل اشترى نشاطاً محدداً (مثال: مطعم):
1. قم بإنشاء مشروع جديد للعميل على [Supabase Dashboard](https://supabase.com).
2. افتح **SQL Editor** في المشروع الجديد.
3. انسخ محتوى الملف `01_core_erp.sql` والصقه واضغط **RUN**.
4. انسخ محتوى الملف `02_addon_restaurants.sql` والصقه واضغط **RUN**.
5. مبروك! قاعدة بيانات العميل جاهزة ومهيأة للتشغيل فوراً.

### السيناريو ب: العميل اشترى المنظومة الشاملة بكل المديولات:
1. افتح **SQL Editor** في مشروع العميل على Supabase.
2. افتح الملف المجمّع `00_full_enterprise_all_in_one.sql`.
3. انسخ المحتوى بالكامل واضغط **RUN**.
4. تم تأسيس كافة الجداول، الدوال، سياسات الأمان، والمحركات المحاسبية لجميع المديولات دفعة واحدة.

---

## 🔒 معايير الأمان وعزل البيانات:
* جميع الحزم مزودة بسياسات **Row Level Security (RLS)** لضمان العزل التام للمنظمات والشركات (`organization_id`).
* تم تزويد الحزم بدوال **RPC** اللازمة لإعادة احتساب المخزون اللحظي وتسوية الحركات المحاسبية بدقة متناهية.
