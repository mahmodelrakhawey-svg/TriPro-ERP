# دليل تشغيل برنامج المساعد المحلي للتوقيع الإلكتروني (TriPro ETA Local Signer)

## 📌 نبذة عامة
نظراً لأن متصفحات الويب الحديثة (Chrome, Edge, Firefox) تعمل داخل بيئة حماية أمنية معزولة (Sandbox) تمنع الوصول المباشر إلى منافذ الـ USB أو الشهادات الرقمية المادية، قامت **TriPro ERP** بتطوير هذا الخادم المساعد خفيف الوزن ليقوم بدور حلقة الوصل الآمنة بين واجهة البرنامج السحابية وفلاشة التوقيع الرقمي الموصولة بجهاز المحاسب أو الكاشير.

---

## 🛠️ متطلبات التشغيل
1. **نظام التشغيل:** Windows 10 / 11 أو Windows Server.
2. **فلاشة التوقيع الرقمي (USB Token):** الصادرة من إحدى الشركات المعتمدة (مثل Egypt Trust أو شركة مصر للمقاصة).
3. **برنامج تشغيل الفلاشة (Token Driver):** مثل برنامج `SafeNet Authentication Client` أو `ePass2003` الخاص بالشركة المزودة.
4. **بيئة Node.js (اختياري لكن مستحسن):** إصدار LTS من موقع [nodejs.org](https://nodejs.org).

---

## 🚀 طريقة التشغيل
1. قم بتوصيل فلاشة الـ USB بجهاز الكمبيوتر والتأكد من إضاءة الليد بها.
2. اضغط مرتين على ملف:
   ```cmd
   start-signer.bat
   ```
3. ستظهر نافذة موجه الأوامر باللون الأخضر تفيد بأن الخادم يعمل بنجاح على العنوان:
   `http://localhost:8500`
4. ادخل إلى نظام **TriPro ERP** -> الإعدادات -> إعدادات الفاتورة الإلكترونية (ETA)، وستجد مؤشر التوقيع تحول إلى **🟢 متصل وجاهز**.

---

## 🛡️ الأمان والخصوصية
- الخادم يعمل محلياً فقط على العنوان الداخلي `127.0.0.1` ولا يمكن لأي جهاز خارجي الوصول إليه عبر الشبكة.
- يتم استقبال النص القانوني للفاتورة وتوقيعه دون تخزين أي بيانات سرية أو أرقام سرية للمنشأة.
